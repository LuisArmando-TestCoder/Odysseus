# 03 — Adversarial Critique & Refinement

Each intervention steelmanned against, then refined.

## S1 synthesis screening
- **Attack:** (a) dual-use sequences are indistinguishable from legitimate orders — blocklists whack-a-mole; (b) orders can be split/re-coded; (c) screening is a privacy/civil-liberties encroachment; (d) moves offshore/DIY if unilateral.
- **Refinement:** Replace pure blocklists with **behavioral anomaly detection** (order provenance, combination, downstream-use attestation). Make screening **universal across all providers** so no unscreened market exists (network effect). Use **zero-knowledge screening** so a provider proves an order was screened *without revealing the sequence* — killing the privacy objection. *(Benchmarks: AML transaction monitoring + zero-knowledge proofs.)*

## S2 biosurveillance
- **Attack:** (a) privacy backlash and genomic-data misuse; (b) "detected too late anyway" for stealth pathogens; (c) false-alarm fatigue.
- **Refinement:** **Privacy-preserving metagenomics** (detect "novel virus present" without reading host genomes). Pair detection with **pre-approved agnostic countermeasures** so every signal triggers a rehearsed response — detection without response capacity is theater. Set explicit sensitivity/specificity targets to bound alarm fatigue.

## S3 platform vaccines / antivirals
- **Attack:** (a) viral escape from strain-specific vaccines; (b) manufacturing bottlenecks and vaccine nationalism; (c) antivirals also select resistance.
- **Refinement:** Bias toward **host-target antivirals** (escape-resistant). Make manufacturing **modular and pre-distributed** (containerized fill-finish, regional foundries). Pre-negotiate allocation *before* crisis to remove the nationalism move from the game tree.

## S4 lab regime
- **Attack:** (a) complacency and regulatory capture; (b) labs are only one failure mode — untouched by intentional actors.
- **Refinement:** Treat as **defense-in-depth, not a silver bullet.** Add third-party verification + no-blame reporting (just culture) so compliance is observable. Scope it as one layer alongside S1/M3.

## M1 intrinsic safety
- **Attack:** (a) recoded organisms can be re-engineered back; (b) kill switches fail; (c) only secures legitimate labs, not intent.
- **Refinement:** Intrinsic safety is not a guarantee but a **cost-raiser** — it converts "trivially capable" into "hard and detectable," pairing with S1 tracking to make the forbidden-corner path expensive and noisy. **Layer, don't rely.**

## M2 artificial immune system
- **Attack:** (a) the design tools are themselves dual-use — the same universal antigen design can design pathogens; (b) over-engineering and centralization risk.
- **Refinement:** **Separate design from synthesis authorities** (air-gap defensive vs. offensive capability). Distribute the system so no single control plane becomes a target.

## M3 global governance
- **Attack:** (a) sovereignty and free-riding; (b) verification gaps (state concealment); (c) treaties ratify the least common denominator.
- **Refinement:** Pursue **"open science + verified synthesis"** — never ban knowledge, *track its instantiation* (falsifiable). Make compliance **resource-attractive** (shared observatories, pandemic insurance, market access) so joining is self-interested.

## M4 information-hazard governance
- **Attack:** (a) censorship harms defense (crypto export-control history shows self-harm); (b) chills basic research; (c) secrecy breeds distrust.
- **Refinement:** **Differential disclosure, not blanket secrecy** — defensive info open; capability-enabling specifics escrowed/time-embargoed; keep the *publish* default, gate only the *instantiation* path (aligns with M3).

## L1 planetary loop
- **Attack:** (a) false-positive alarm fatigue; (b) the immune system becomes the pathogen (governance capture); (c) centralization = single point of failure.
- **Refinement:** No single control plane. Red-team the defense itself. Publish alarm forensics to sustain trust — **calibration is a first-class goal.**

## L2 redundancy / off-world
- **Attack:** (a) morally fraught ("save some while others perish"); (b) decades away; (c) refuges can become targets or caste systems.
- **Refinement:** Start with **earth-side distributed resilience** (energy/food/pharma independence) that helps everyone *now*; treat off-world as insurance, explicitly decoupled from elite escape.

## L3 self-limiting technology
- **Attack:** (a) brakes are bypassable; (b) reflexive institutions are slower than capability growth; (c) "circuit-breaker" triggers are politically manipulable.
- **Refinement:** Prefer **hard technical brakes** (at the substrate) over policy brakes. **Pre-commit trip conditions** in advance of crisis to remove discretion.

## L4 goal shift
- **Attack:** (a) realism — coordination fails exactly when stakes are highest; (b) norms are slow.
- **Refinement:** **Design for coordination under defection:** small cost-effective clubs with widening benefits, costly-to-defect architecture, prestige/insurance bundling (mechanism design, not moral appeal).

## Refined portfolio (post-critique)

Defense-in-depth across four layers, each closing a different gate of the extinction chain:

1. **Prevent emergence** (gate 1) — S1 universal screened synthesis + M1 intrinsic safety + M4 differential disclosure (raise the cost and visibility of entering the forbidden corner).
2. **Detect instantly** (gate 2) — S2 biosurveillance (privacy-preserving, response-coupled) + L1 hour-scale loop.
3. **Neutralize agnostically** (gates 3–5) — S3 host-target antivirals + M2 artificial immune system + pre-positioned manufacturing.
4. **Absorb & recover** (gate 6) — S4–S5 buffers + L2 redundancy.

Homeostatic layers (1 partial, 2, 3 partial) hold the line; homeodynamic layers (M1, M2, L1–L3) do the tail-shaving.
