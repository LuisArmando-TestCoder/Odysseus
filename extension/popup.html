Odysseus Bridge

How to enable this extension (step-by-step)
  1. Load the extension unpacked.
    Chrome: open chrome://extensions → toggle Developer mode (top-right) → click Load unpacked → select the extension/ folder.
    Firefox: open about:debugging#/runtime/this-firefox → Load Temporary Add-on… → select manifest.json.
  2. Confirm it's enabled.
    The Odysseus Bridge icon should appear in your toolbar.
  3. Open Google or YouTube and log in.
    Go to google.com (AI Mode) or youtube.com ("Ask") and make sure you're signed in — the AI-mode button only appears for logged-in users.
  4. (Optional) Set your Odysseus URL.
    Right-click the extension → Options → set the base URL if it isn't http://127.0.0.1:5173.
  5. Use it.
    Type a question above and click Ask AI, or highlight text → right-click → Ask AI (Odysseus), or press Cmd+Shift+Y (Mac) / Ctrl+Shift+Y. The extension auto-detects Google vs YouTube from the active tab.
